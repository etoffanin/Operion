# OPERION

Sistema operacional inteligente para registro e evidência de operações logísticas e industriais.

---

## SOBRE O PROJETO

O Operion nasceu como uma tentativa de modernizar e centralizar o registro operacional de estufagem de containers.

A ideia principal do projeto é transformar processos manuais como gravações separadas, fotos soltas e envio manual de informações em um fluxo único, organizado e mais eficiente.

Esta primeira versão foi desenvolvida como MVP funcional, focando principalmente em estrutura, testes operacionais e validação da ideia.

---

## FUNCIONALIDADES ATUAIS

- Registro de dados da operação
- Captura de fotos diretamente pela câmera
- Gravação operacional via navegador
- Controle de quantidade de bobinas
- Geração de resumo operacional
- Interface responsiva para desktop e mobile
- Estrutura preparada para futuras automações

---

## TECNOLOGIAS UTILIZADAS

- HTML5
- CSS3
- JavaScript

- MediaRecorder API
- Canvas API

---

## OBJETIVO

O Operion foi criado para tentar reduzir:
- processos manuais;
- perda de evidências operacionais;
- desorganização de registros;
- tempo gasto em envio e documentação.

Além disso, o projeto também funciona como estudo prático de desenvolvimento web, arquitetura de aplicações e automação operacional.
